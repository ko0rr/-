# A/B-тест новой формы оплаты ЖКХ

Анализ результатов A/B-теста формы оплаты ЖКХ с автозаполнением реквизитов. Цель исследования - проверить, увеличивает ли новая форма конверсию в успешную оплату.

## Данные

Эксперимент проводился с 1 по 30 апреля 2024 года. Датасет содержит информацию о пользователях, распределении по A/B-группам и попытках оплаты.

После очистки данных: **1 501 активный пользователь и 2 659 попыток оплаты**.

## Методология

- Проверка качества данных и обработка некорректных записей.
- Анализ воронки оплаты и конверсий между этапами.
- Расчёт пользовательской и платежной конверсий.
- Кластерный bootstrap по пользователям для оценки доверительного интервала.
- Перестановочный тест для проверки статистической значимости.
- Визуализация результатов с помощью Matplotlib.

## Основные результаты

| Метрика | Группа A | Группа B |
|---|---:|---:|
| Конверсия в успешную оплату | 49,77% | 64,40% |
| Пользовательская конверсия | 65,65% | 80,40% |

**Эффект:** +14,63 п.п. (+29,39% относительно контроля).

**95% доверительный интервал:** [+11,04; +18,32] п.п.

**p-value:** < 0,00005.

Новая форма статистически значимо повышает конверсию в успешную оплату. Рекомендован поэтапный запуск.
